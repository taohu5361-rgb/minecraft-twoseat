# TwoSeat 0.2.2 天气、模拟与帧率测试

2026-11-12，北京时间。正式Forge客户端加载单个TwoSeat JAR，Minecraft 1.20.1 / Forge 47.3.33 / Java 17。

## 发现与修复

P2漏掉了原版每刻调用的LevelRenderer.tick。实际雨天、双玩家相距800格时，旧版10秒内P1天气时钟前进200刻，P2前进0刻，P2动画时间回退200次。此问题来自动画时间反复重放。

补齐P2的渲染器刻、ClientLevel.animateTick和ParticleEngine.tick；ParticleState分开两名玩家的活动粒子、跟踪发射器、待加入队列和粒子组计数，提供器、精灵图集和纹理继续共用。音频继续以P1为监听中心。没有加入LOD，也没有降低P2生物或方块的模拟频率。

修复后同一回归中，P2雨线回退0次；两视图中牛的客户端刻数均在10秒内前进200刻、动画时间0次回退，P2牛实际移动的最大逐帧插值步长约0.012格。两套活动粒子容器不同，粒子所属客户端世界混入数均为0；只发给P2的营火烟粒子只存在于P2，并正常增长年龄。

## 8区块加载／8区块模拟

本机试玩实例的两项设置均为8，集成服务器和两个客户端收到的距离也为8。每名真实玩家的区块票据交给原版服务器维护；同一服务器的重叠区域只模拟一次。没有添加低频、简化实体或低精度区块分支。

在两玩家相距800格、没有模拟范围重叠的位置，分别检查中心及沿X方向第6、第7个区块的盔甲架和熔炉：检查实体刻数、燃烧/烹饪进度及实际产物。原版出生区块等额外加载票据继续保留，不能把“距离设置为8”理解为服务器绝不会加载额外区块。精选结果见evidence/0.2.2；这属于代表性模拟检查，跨维度、死亡重生、复杂模组容器和全部生物行为仍未完整验收。

## 帧率结果

| 场景 | 整窗平均FPS | 1% low FPS | P99帧时间ms | 服务端平均刻时间ms（两次范围） |
| --- | ---: | ---: | ---: | ---: |
| 单视角／晴天 | 1043.6 | 419.1 | 2.32 | 2.80–3.01 |
| 近距离分屏／晴天 | 655.2 | 230.8 | 4.19 | 3.72–3.84 |
| 远距离分屏／晴天 | 643.2 | 250.7 | 3.86 | 5.97–6.22 |
| 远距离分屏／雨天 | 512.3 | 221.8 | 4.36 | 6.40–6.69 |

每个场景两次15秒采样，以上合并两次真实全局帧间隔计算。分屏FPS指完成左右两视图的一整个窗口帧；1% low为最慢1%帧时间的平均值取倒数，P99为帧时间99百分位。全部8份样本均保持前台焦点和固定相机；静止检查容许小于0.001度/0.00001格的数值尾差。记录保留全部原始帧间隔，见evidence/0.2.2/fps-*.json及fps-summary.json。

- CPU：AMD Ryzen 7 9700X；GPU：NVIDIA GeForce RTX 5070，驱动616.92。GPU原有180W功耗上限保留，未修改驱动、功耗或后台服务。
- JVM最大堆4GiB，1920×1080，加载8／模拟8，精细画质，全部粒子，无光影或其他玩法/优化模组。
- 关闭垂直同步，帧率滑块260（原版“不限帧”）。这是吞吐量测试；试玩实例保留原有的显示限帧设置，只将距离改为8／8。
- 本表为恢复工作后重新采集的开放视角数据；此前遮挡视角数据已排除。游戏内原版FPS末秒计数也随样本保存，用来交叉核对帧间隔计算。
- 固定主视角X/Z=(128.5,48.5)、Y=160、yaw=0、pitch=35；P2近处X/Z=(136.5,48.5)，远处=(928.5,48.5)，均在Y=160的单方块观察点上。视野包含自然森林、山坡及海面，先通过截图确认没有贴墙遮挡；各阶段的相机起止坐标随样本保存。先预热，再采样；首次生成、传送和地形加载阶段不纳入表格。
- 远近场景可见地形不同，帧率受具体画面内容影响。数据代表本机固定测试场景；生物密集、复杂红石、其他分辨率和长期游玩需另测。

## 输入回归

最终同一JAR通过原17项Controlify移动、转向、按键隔离、放置/挖掘/PvP、背包取放、双背包及断开回退测试；首次CONTROLLER_CONNECTED接入也无阻塞向导。交互夹具先通过真实肩键切到已准备的方块格，避免沿用之前游玩的空手选择状态。自动输入状态源不能代替全部硬件组合的人工作用验收。

## 复测入口

仅在可丢弃TwoSeat测试世界，以-Dtwoseat.probe=true启动。设置TWOSEAT_TEST_GAME和TWOSEAT_TEST_OUTPUT后，依次运行tests/controller/weather_regression.py、simulation_regression.py、frame_benchmark.py。普通安装probe默认关闭。源码包含探针，发布包不含测试存档、Minecraft本体或个人配置。
